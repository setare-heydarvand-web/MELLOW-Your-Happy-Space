# MELLOW — Your Happy Space 🌷

MELLOW is a personal productivity dashboard designed to make everyday planning feel simple, organized, and enjoyable.

## ✨ Features

- **Task Manager:** Add, edit, delete, and track daily tasks.
- **Task Filters:** View all, active, and completed tasks.
- **Progress Tracking:** Monitor completed tasks and daily progress.
- **Focus Timer:** Stay focused with a customizable timer.
- **Snake Game:** Take a fun break with a classic Snake game.
- **Responsive Design:** A clean interface designed for different screen sizes.

## 🛠️ Built With

- HTML5
- Tailwind CSS
- JavaScript
- Browser Local Storage

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Run the project using a local development server.
4. Open the local URL in your browser.
